# AnchorTodo

Windows 10 / 11 x64 向けの、小さな常駐 Todo アプリです。Rust 2021 と Win32 API を使い、単体のポータブル実行ファイルを目指します。

手元で動作確認した v1.4.0 の機能を、このリポジトリへ少しずつ導入しています。各 PR を個別に確認できる大きさに分け、デフォルトブランチへ順番にマージして進めます。

現在の導入順は [開発ロードマップ](ROADMAP.md) にまとめています。

## 目指している機能

- 画面右下に配置する小さな Todo ウィンドウ
- Markdown ファイルへの保存と外部編集の反映
- ホットキー、通知領域のアイコン、任意の自動起動
- ダークテーマと白背景のライトテーマ
- チェック欄で完了、タスク名のクリックで編集
- ドラッグによる並べ替え
- 最前面と最後面の切り替え

## PR の進め方

ロードマップの番号順にブランチを作り、PR を確認してからマージします。細かいコミットを残すマージ方法として、GitHub の **Create a merge commit** を使います。

新しい PR のコミットは、その作業を進める日に作成します。各段階のビルドを確認しながら、v1.0.0、v1.1.0、v1.2.0、v1.3.0、v1.4.0 の順に機能をそろえます。
